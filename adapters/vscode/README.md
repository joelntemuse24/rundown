# VS Code / Cursor webview (and Copilot users)

A minimal extension: the command **Rundown: Open replay** asks for a replay URL or id and iframes `/r/:id` from `rundown.url`. Nothing else.

Install from this folder with `npx @vscode/vsce package` and then "Install from VSIX", or open the folder and press F5.

Copilot has no hook Rundown can use. Copilot users paste a PR URL on the Rundown site, or open the replay here.
